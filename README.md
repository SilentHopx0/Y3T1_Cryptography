## ⚡ Overview

Welcome to my **Year 3 Cybersecurity Cryptography** repository! This repo contains all hands-on lab experiments, cryptographic algorithm implementations, hash functions, and protocol simulations completed during the course.

> *"There are two kinds of cryptography in this world: cryptography that will stop your kid sister from reading your files, and cryptography that will stop major governments from reading your files."* — Bruce Schneier

---

## 📂 Lab Organization

No cluttered file trees here — everything is organized simply by week:

- Each week's lab assignments, code, and supplementary files live directly inside its respective folder named **`W(Number of weeks)`** (e.g., `W1`, `W2`, `W3`, ...).
- Simply jump into the folder of the week you want to inspect!

---

## 🛠️ Stack & Topics Covered

- **Language:** Go (Golang)
- **Core Topics:**
  - Bitwise operations & modular arithmetic
  - Symmetric & Asymmetric encryption
  - Cryptographic Hash Functions (`MD5`, `SHA-1`, `SHA-256`, `SHA-3`, `SHA-512`)
  - Practical crypto labs & secure tunnels (VPN simulations)

---

## 🚀 How to Run

Navigate into any week's lab folder:

```bash
# Go into the target week's lab
cd W(Number of weeks)

# Run the lab
go run .
```
